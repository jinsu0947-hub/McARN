# SPEC_RoadProfile — 도로 종단선형 평활화

버전 0.1 · 대상: Arnis 생성 마인크래프트 월드 후처리

---

## 0. 목적

Arnis가 생성한 도로는 지형 고도를 그대로 따라가 한 블록 단위로 계단처럼 튄다. 이 명세는 도로 표면을 연속적인 종단선형으로 다시 깎아, 반블록 단위로 매끄럽게 오르내리는 도로를 만드는 처리를 정의한다.

**이 명세의 범위는 도로 표면과 그 직접 부속물까지다.** 건물 재접지, 파사드, 가로 요소는 후속 명세에서 다룬다.

---

## 1. 좌표 규약

### 1.1 반블록 단위 정수 높이

모든 높이는 **반블록 단위 정수** `y2`로 다룬다.

```
y2 = y * 2
```

- `y2`가 짝수 → 해당 위치는 온전한 블록 상면
- `y2`가 홀수 → 아래 온전한 블록 + 그 위 하단 슬래브

슬래브를 예외 처리가 아닌 기본 단위로 두기 위한 규약이다. 모든 제약 검사와 최적화는 `y2` 정수 공간에서 수행한다.

### 1.2 경사 표현

한 블록 수평 이동당 `y2` 변화량을 경사로 정의한다.

| Δy2 / 블록 | 실제 경사 | 비고 |
|---|---|---|
| 1 | 약 26.6° | 슬래브 한 단, 이동에 걸리지 않음 |
| 2 | 45° | 상한 |

## 2. 입출력

### 2.1 입력

- Arnis가 생성한 마인크래프트 월드 폴더 (원본은 읽기 전용, 복사본에 작업)
- 처리 대상 영역 (블록 좌표 bbox). 미지정 시 월드 전체

### 2.2 출력

- 도로가 재작성된 월드 복사본
- **도로망 그래프 파일** `roadgraph.json` (§2.4)
- 처리 로그: 구간 수, 노드 수, 이동량 통계, 옹벽 생성 위치, 제외된 구간 목록

### 2.3 도로망 그래프 `roadgraph.json`

P2~P6에서 계산된 도로망 구조를 후속 단계가 재사용할 수 있도록 저장한다. 월드에 표지판이나 데이터 블록으로 심지 않고, 월드 폴더와 나란히 별도 파일로 둔다.

```json
{
  "version": "0.1",
  "bbox": [x_min, z_min, x_max, z_max],
  "nodes": [
    {
      "id": "n0012",
      "pos": [x, z],
      "y2": 128,
      "degree": 4,
      "segments": ["s0031", "s0032", "s0048", "s0049"]
    }
  ],
  "segments": [
    {
      "id": "s0031",
      "ends": ["n0012", "n0013"],
      "length": 42,
      "points": [
        {
          "pos": [x, z],
          "y2": 128,
          "road_half_width": [3, 3],
          "sidewalk_width": [2, 0],
          "structure": "ground"
        }
      ]
    }
  ],
  "excluded": [
    { "reason": "plaza", "bounds": [x_min, z_min, x_max, z_max] }
  ]
}
```

- `y2`: §1.1 반블록 단위 정수 높이 (확정값)
- `road_half_width`: 중심선 기준 [좌, 우] 차도 폭
- `sidewalk_width`: [좌, 우] 인도 폭. 0이면 인도 없음
- `structure`: `ground` / `elevated` / `tunnel`
- `excluded`: 처리에서 제외된 영역. 후속 단계도 동일하게 건너뛴다

**후속 단계에서의 용도**

| 용도 | 사용 항목 |
|---|---|
| 건물 재접지 | 가장 가까운 구간 점의 `y2` |
| 프론티지 판정 | 중심선에서 법선 방향으로 뻗어 처음 만나는 건물 면 |
| 주요 가로 선정 | 구간 단위 선택 |
| 태깅 순회 순서 | 구간을 따라 이동 |
| 가로 요소 배치 | 인도 폭이 있는 지점에 일정 간격 |

### 2.4 원칙

- 원본 월드는 절대 수정하지 않는다
- 동일 입력 + 동일 파라미터 → 동일 출력 (결정론)
- 파라미터를 바꿔 반복 실행할 수 있어야 한다

## 3. 처리 파이프라인

### P1. 도로 마스크 추출

도로 표면 블록 집합을 `ROAD_BLOCKS`로 정의한다. 각 `(x, z)`에 대해:

- 수직으로 훑어 `ROAD_BLOCKS`에 속하는 최상단 블록을 찾는다
- 해당 위치의 `y2`를 기록한다 (슬래브면 홀수)

결과: 2D 불리언 마스크 `M[x][z]`와 원본 높이맵 `H0[x][z]`.

인도 재질은 별도 집합 `SIDEWALK_BLOCKS`로 정의하되, 마스크에는 포함하지 않는다. P5에서만 사용한다.

### P2. 중심선 그래프 생성

1. `M`을 세선화(thinning)하여 폭 1의 골격을 얻는다
2. 골격 픽셀의 8-이웃 연결 차수를 센다
   - 차수 ≥ 3 → **노드** (교차로)
   - 차수 1 → **말단**
   - 차수 2 → 구간 내부 점
3. 노드/말단 사이의 픽셀 열을 **구간(segment)** 으로 묶는다
4. 길이가 `MIN_SPUR_LENGTH` 미만인 말단 구간은 세선화 부산물로 보고 제거한다
5. 제거 후 차수가 2가 된 노드는 양쪽 구간을 병합한다

결과: 노드 집합 `N`, 구간 집합 `S`. 각 구간은 순서 있는 픽셀 열과 각 픽셀의 원본 높이 `H0`를 갖는다.

### P3. 구조물 판정

각 구간 픽셀에 대해 상태 플래그를 부여한다.

**뜬 구조 (다리·고가)**
- 도로 표면 아래로 `AIR_DEPTH_THRESHOLD` 칸 이상 연속하여 공기 또는 물이면 `ELEVATED`

**덮인 구조 (터널)**
- 도로 표면 위로 `TUNNEL_CLEARANCE` 칸 이내에 고체 블록 천장이 있으면 `TUNNEL`

**지상**
- 그 외 `GROUND`

플래그는 P4/P6/P7의 동작을 바꾼다. 판정은 원본 높이 기준으로 1회만 수행하고 이후 고정한다.

구간 내에서 플래그가 바뀌는 지점(다리 진입부 등)은 **전이점**으로 표시한다.

### P4. 노드 높이 확정 (전역 해)

교차로에 모이는 도로는 높이가 하나여야 한다. 노드 높이 `h_n`을 미지수로 두고 전체 네트워크를 한 번에 푼다.

**목적함수**

```
minimize  Σ_n  w_ground(n) * (h_n - H0_n)²
        + Σ_(a,b)∈E  w_slope * (h_a - h_b)² / d(a,b)
```

- 첫 항: 원지형 이탈 페널티
- 둘째 항: 인접 노드 간 경사 페널티. `d`는 구간 길이
- `w_ground(n)`: `GROUND` 노드는 1.0, `ELEVATED` 노드는 0 (지형을 따라갈 이유가 없음), `TUNNEL` 노드는 1.0

**제약**

```
|h_a - h_b| / d(a,b) ≤ MAX_SLOPE
```

선형 최소자승으로 풀고, 제약 위반 시 해당 간선에 페널티를 가중하여 재계산한다(반복 최대 `MAX_ITER`회). 결과는 실수값으로 두고 P5에서 반올림한다.

> 구간별로 따로 다듬으면 교차로에서 반드시 어긋난다. 노드 해를 먼저 확정하는 것이 이 파이프라인의 핵심이다.

### P5. 구간 내부 프로파일

양 끝 노드 높이가 고정된 상태에서 구간 내부 각 픽셀 `i`의 높이 `h_i`를 구한다.

**목적함수**

```
minimize  Σ_i  w_ground(i) * (h_i - H0_i)²
        + λ_curve * Σ_i  (h_(i-1) - 2*h_i + h_(i+1))²
```

- 첫 항: 원지형 추종. `ELEVATED` 픽셀은 `w_ground = 0`
- 둘째 항: 2차 차분(꺾임) 페널티. 이것이 매끄러움을 만든다

**제약**

```
|h_i - h_(i-1)| ≤ MAX_SLOPE
h_0 = 노드 높이,  h_last = 노드 높이   (고정)
```

**전이점 처리**
- 다리 진입 노드는 고정점으로 취급한다. 다리 구간과 지상 구간이 같은 높이를 공유하므로 단차가 생기지 않는다
- `ELEVATED` 구간은 지형 추종이 꺼진 채 꺾임 페널티만 남으므로, 양 끝을 부드럽게 잇는 곡선이 나온다. 다리로서 자연스러운 형태다

**정수화**
- 실수 해를 `y2` 정수로 반올림한다
- 반올림 후 경사 제약을 재검사하고, 위반 시 해당 구간을 국소 재분배한다

결과: 중심선 높이맵 `Hc`.

### P6. 횡단면 스윕

중심선 각 픽셀에서 진행 방향의 법선을 따라 좌우로 뻗으며 폭을 잰다.

1. 중심선에서 좌우로 한 칸씩 이동하며 `ROAD_BLOCKS` 연속 여부를 확인. 끊기는 지점이 **차도 경계**
2. 차도 경계에서 한 칸 더 확인:
   - `SIDEWALK_BLOCKS`이면 인도로 판정하고 계속 뻗어 인도 폭을 잰다
   - 아니면 거기서 단면 종료

**인도 유무를 사전에 알 필요가 없다.** 있으면 따라오고 없으면 끝난다. 구간마다 폭이 달라도 픽셀 단위로 재측정하므로 자동 처리된다.

**높이 배정**
- 차도 전 폭: `Hc`와 동일
- 인도: `Hc + CURB_HEIGHT` (기본 1, 즉 반블록)
- 연석: 차도와 인도 경계 한 줄. 인도 높이의 슬래브로 채운다

`TUNNEL` 픽셀은 천장까지의 상대 오프셋을 기록해 둔다(P7에서 사용).

### P7. 블록 기록

각 `(x, z)` 위치의 목표 높이 `y2`에 대해:

- **짝수** → `floor(y2/2)`에 온전한 블록
- **홀수** → `floor(y2/2)`에 온전한 블록 + 그 위에 하단 슬래브

재질은 원본 위치의 재질을 그대로 유지한다. 이 명세는 형태만 다루고 재질은 바꾸지 않는다.

**부속 구조 이동**

표면이 `Δy2`만큼 이동했을 때 함께 옮겨야 하는 것:

| 구조 | 처리 |
|---|---|
| `ELEVATED` 하부 (교각, 난간) | 상판과 동일한 `Δy2`만큼 수직 이동. 교각 하단은 지면에 닿을 때까지 연장 |
| `TUNNEL` 천장·측벽 | 상대 오프셋 유지한 채 동일 이동 |
| 도로 위 표지·가로등 | 동일 이동 |

상판만 옮기고 하부를 두면 다리가 기둥에서 떨어진다. 터널 천장을 안 옮기면 통행이 막힌다.

**정리**
- 이전 표면이 있던 자리 중 새 표면보다 위인 블록은 공기로 지운다
- 새 표면 아래 공백은 `FILL_BLOCK`으로 메운다

### P8. 주변 지형 정리

도로가 원지형에서 벗어난 만큼 주변을 정리한다. `GROUND` 픽셀에만 적용한다.

단면 바깥 경계에서 시작하여 `TAPER_WIDTH` 블록에 걸쳐 원지형 높이로 선형 보간한다.

`|Hc - H0| > RETAINING_THRESHOLD`이면 테이퍼 대신 **옹벽**을 세운다. 억지로 흙을 쌓거나 깎는 것보다 결과가 깔끔하다.

## 4. 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `MAX_SLOPE` | 2 | 블록당 최대 `y2` 변화. 2 = 45°. 상한이며 목표가 아님 |
| `λ_curve` | 조정 필요 | 꺾임 페널티 가중치. 클수록 매끄럽고 원지형에서 멀어짐 |
| `w_slope` | 조정 필요 | 노드 간 경사 페널티 가중치 |
| `RETAINING_THRESHOLD` | 3 | 옹벽 전환 높이차 (블록) |
| `TAPER_WIDTH` | 4 | 주변 지형 보간 폭 (블록) |
| `CURB_HEIGHT` | 1 | 인도 높이 오프셋 (`y2` 단위, 1 = 반블록) |
| `MIN_SPUR_LENGTH` | 4 | 이보다 짧은 말단 구간 제거 (블록) |
| `AIR_DEPTH_THRESHOLD` | 3 | 뜬 구조 판정 하부 공기 깊이 |
| `TUNNEL_CLEARANCE` | 6 | 터널 판정 천장 높이 |
| `MAX_ITER` | 10 | 노드 해 제약 반복 상한 |

**실질적으로 조정할 값은 셋이다.** `λ_curve`, `w_slope`, `RETAINING_THRESHOLD`. 나머지는 기본값으로 두고 시작한다.

## 5. 실패 처리

| 상황 | 처리 |
|---|---|
| 노드 해가 `MAX_ITER` 내 수렴 실패 | 해당 연결 성분을 처리에서 제외하고 원본 유지, 로그 기록 |
| 구간에서 정수화 후 경사 제약 위반 해소 실패 | 해당 구간 원본 유지, 로그 기록 |
| 마스크 연결 성분이 지나치게 큼 (광장 등 면 형태) | 세선화 결과가 무의미하므로 제외, 로그 기록 |
| 부속 구조 이동 시 다른 구조와 충돌 | 이동 취소, 해당 구간 원본 유지, 로그 기록 |

**모든 실패는 원본 유지로 처리한다.** 부분적으로 안 다듬어진 도로가 망가진 도로보다 낫다.

## 6. 검증

게임에 진입하지 않고 확인한다.

1. 작은 타일(예: 200×200 블록) 하나만 먼저 처리
2. 렌더러로 상면·사선 이미지를 뽑아 육안 확인
3. 자동 검사:
   - 도로 마스크 전 픽셀에서 인접 `y2` 차이가 `MAX_SLOPE` 이하인가
   - 각 노드에 모이는 구간 끝점 높이가 모두 동일한가
   - 뜬 구조 하부에 지지 구조가 연결되어 있는가
   - 터널 내부 통행 높이가 확보되어 있는가

3번은 회귀 검사로 매 실행 후 자동 수행한다.

## 7. 범위 밖 (후속)

- **건물 재접지** — 도로 높이 변경으로 건물이 뜨거나 묻히는 문제. 건물을 통째로 수직 이동시키는 방식. 실내가 구현되어 있으므로 바닥만 늘리는 방식은 쓰지 않는다. 2칸 이상 차이나는 건물만 대상
- **파사드 자동 채움** — 실내 바닥 위치로 층 경계를 읽어 창문 띠 배치
- **가로 요소** — 전주, 전선, 돌출 간판, 실외기

처리 순서는 위 나열 순서를 따른다. 도로를 나중에 고치면 건물을 다시 손봐야 한다.
